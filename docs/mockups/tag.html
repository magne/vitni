Color-picker specimen — the dialog the Swatch button opens; no native <input type=color> (its chrome is unstyleable), so presets and a hex field carry it:
Choose a color

The grid is .color-grid — eight columns of .swatch-btn, the current colour carrying .sel (an inset accent ring, so selecting never resizes the swatch). Selection is role="listbox"/option; the hex field takes any colour the presets don't cover, and Save writes it into the record draft — the picker commits nothing on its own.
