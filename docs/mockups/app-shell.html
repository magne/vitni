Record tabs

The strip shows only on entity categories, beside the Explorer — the Dashboard is full-width and has none. A tab is a record you have open; drag one onto the detail pane (or press ⌘⇧1…9) to dock it side-by-side.

The ● marker means the tab holds unsaved work — either an unsaved draft (nothing stored yet, as with “New person”) or unsaved edits to an already-saved record (“Mary Doe”). Both make ⌘W and ⌘Q ask before discarding — see Record editing. The marker is a glyph plus an “unsaved changes” accessible name, not colour alone (WCAG 1.4.1); the docked tab's accent underline is the same convention.
