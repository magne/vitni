Import

One Tool::Import screen, two independent wizards. A mode switch (issue #191) picks Bulk file import — a local file through a bulk-import plugin, the GUI counterpart of genealogy import <plugin> <file> (--new NAME PATH | --into NAME) — or Assisted online import, the Digitalarkivet wizard below. Bulk import's target radio reuses the Preferences "Register workspace…" fields for a brand-new workspace, and confirms first (a Modal, no --yes equivalent) before writing into an existing workspace that already holds persons.

Assisted online import — Digitalarkivet

Fetch, review, and import one record at a time. This wizard renders a typed present payload sent by an assisted-import plugin — it is not the ADR 0022 plugin-UI vocabulary. The plugin fetches pages over the sandboxed net capability, stores the scan through media-store, and proposes fields; you confirm or edit each record before anything is written. Every imported claim is a low-confidence Software-agent assertion with an ExternalId back to the source URL, so a re-run imports no duplicates.
