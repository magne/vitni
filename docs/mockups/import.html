Import

One Tool::Import screen, two independent wizards. A mode switch (issue #191) picks Bulk file import — a local file through a bulk-import plugin, the GUI counterpart of vitni import <plugin> <file> (--new NAME PATH | --into NAME) — or Assisted online import, the Digitalarkivet wizard below. Bulk import's target radio reuses the Preferences "Register workspace…" fields for a brand-new workspace, and confirms first (a Modal, no --yes equivalent) before writing into an existing workspace that already holds persons. When that workspace already holds earlier imports in the same format, the import starts at once and the confirm comes once the file is read: it asks which tree the file belongs to — a later export of one of them, or a different tree. Vitni proposes the tree whose earlier imports hold the file's people and families under the same header fingerprint, starts the select on it and says why. A later Vitni GEDCOM export of one workspace always shares that fingerprint, because the exporter writes the workspace's id as HEAD.FILE (ADR 0043). With no clear match nothing is chosen and the import waits for the answer (ADR 0037 §3; the CLI's --dataset / --new-dataset, or its prompt, which --yes accepts). Cancel there writes nothing. Every import is recorded as an import run. The plugin reads the whole file first, naming its own steps; Vitni then writes the records, and a cancel before then writes nothing.

Assisted online import — Digitalarkivet

Fetch, review, and import one record at a time. This wizard renders a typed present payload sent by an assisted-import plugin — it is not the ADR 0022 plugin-UI vocabulary. The plugin fetches pages over the sandboxed net capability, stores the scan through media-store, and proposes fields; you confirm or edit each record before anything is written. Every imported claim is a low-confidence Software-agent assertion with an ExternalId back to the source URL, so a re-run imports no duplicates. Besides the person, a record brings its birth (dated from the age when the census gives one), its part in the census of its residence — the farm, inside the census municipality — with its place in the household's family, or its part in a church-book event by its role. When a record's person, place, source or repository may already be in your tree, the host itself asks before anything of the record is written (the Match stage below); a record with no possible match never meets that stage.
