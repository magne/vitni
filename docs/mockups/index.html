Phase 5 — UI breadth mockups

A design system and a screen inventory for the genealogy desktop app. Open any screen below; toggle light/dark from the top-right or from a screen's top bar. These are static HTML prototypes — the build plan that turns them into Dioxus screens is plan.md.

Design intent. Entity-category rail + master-detail (not Gramps's mixed category buttons); a always-visible active record; in-app record tabs you can dock side-by-side to compare; and the evidence model made legible everywhere — confidence, sources, evidence-analysis axes, and a free audit trail from the event-sourced core. Both light and dark themes ship from tokens.

Entities — CRUD + detail

👤 Person
The full reference: names, facts, events, citations, media, notes, history.
👪 Family
Neutral partners, children with per-parent relationship types, family events.
📅 Event
Type, structured date, place, participants with roles, citations.
📍 Place
Dated/multilingual names, the enclosed-by hierarchy, coordinates.
📚 Source
Bibliographic fields, repositories, and the citations that use it.
❝ Citation
Evidence editing: confidence + the Evidence Explained axes.
🏛 Repository
Type, addresses, URLs, held sources.
🖼 Media
Gallery + file metadata, checksum, citations.
🗒 Note
Rich text, language + translations, back-references.
🏷 Tag
Name, color, priority, usage.
🧬 DNA test
Provider/kit/type/build, haplogroups, matches. (Rich views: Phase 12.)
🔗 DNA match
Shared cM, segments, shared ancestors. Observation vs conclusion.

Functions

🌳 Pedigree / tree
Ancestor chart with the focus person; view switcher.
⇄ Compare / merge
Duplicate detection + non-destructive, reversible merge.
🌐 Assisted import
Digitalarkivet: fetch a record, review the scan + interpreted fields, import as low-confidence claims. (Phase 8)
🗺 Geography
Point/polygon/multi-polygon geometry, time slider, in-map editing, pluggable provider, succession links. The Place mockup's own Map tab (see place.html) edits one place the same way. (Phase 9)
🔍 Search & ⌘K palette
Global search and the command palette.
⚙ Preferences
Operator, theme, language/locale defaults, date format, override layers.
🧩 Plugin manager
Sandboxed plugins, capabilities, enable/disable.
