Surety scheme

Confidence-level wording

Relabel the five surety levels asserted on every claim (data-model §8) with your own wording. The five levels themselves are fixed (ADR 0027) — this changes only the words shown, never how a claim's evidence is stored or how many levels there are.
Blank fields keep the built-in Fluent-localized wording (“Very Low”, “Low”, …). A filled-in label is shown verbatim in every locale — it is not translated, since it is your own wording. Switching scope shows that scope's own labels.
Where each level's wording comes from
winsVery low — Workspace — workspace.toml
fallbackLow — Shared app — ~/.config/vitni/config.toml
fallbackNormal — Embedded — built-in baseline
fallbackHigh — Embedded — built-in baseline
winsVery high — Workspace — workspace.toml

Keyboard shortcuts

Rebind global shortcuts

Only global shortcuts (active anywhere) can be rebound. Within-screen keys and the g-prefix navigation keys are fixed. Type a chord as mod+shift+alt+key — mod is ⌘ on macOS, Ctrl elsewhere.

Workspace defaults

Where a setting’s value comes from

Each setting resolves through three layers. The first layer that supplies a value wins; the rest are the fallback. Example shown: default confidence for a new assertion.
wins Workspace — family-tree/workspace.toml High
fallback Shared app [workspace-defaults] — ~/.config/vitni/config.toml (live fallback) Normal
fallback Embedded — built-in baseline Normal
This example resolves through the live [workspace-defaults] chain. The separate app-level [defaults] table (e.g. the storage engine for a new workspace) is different: its value is frozen into the workspace at creation, not read live (ADR 0005/0006).
