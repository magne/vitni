Bulk export

Write the whole workspace out through an export plugin. The wizard is a first-party Tool::Export screen (ADR 0013) — the GUI counterpart of genealogy export <plugin> [--output FILE]. There is no native file dialog: you type a destination and see the resolved path live. An empty field or a bare directory is an ExportTarget::Directory and the plugin names the file; a path with a file name is an ExportTarget::File and pins it. The run streams real progress and can be cancelled — cancellation is cooperative, so it takes effect at the plugin's next progress report.
