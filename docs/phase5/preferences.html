Workspace defaults

Where a setting’s value comes from

Each setting resolves through three layers. The first layer that supplies a value wins; the rest are the fallback. Example shown: default confidence for a new assertion.
wins Workspace — family-tree/workspace.toml High
fallback Shared app [workspace-defaults] — ~/.config/genealogy/config.toml (live fallback) Normal
fallback Embedded — built-in baseline Normal
This example resolves through the live [workspace-defaults] chain. The separate app-level [defaults] table (e.g. the storage engine for a new workspace) is different: its value is frozen into the workspace at creation, not read live (ADR 0005/0006).
