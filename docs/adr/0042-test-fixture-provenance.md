# 42. Test fixtures are committed only when the project may redistribute them

- **Status:** Accepted
- **Date:** 2026-09-30

## Context

The `vitni-digitalarkivet` tests parse five Digitalarkivet pages that were saved as the site served them
(`crates/vitni-digitalarkivet/tests/fixtures/{census,churchbook}/`, 258 KB). Their rights were examined
on 2026-09-30:

- **The census pages** (Folketelling 1920 for Greipstad, source 73902) carry a transcription whose
  rights holder is Nasjonalarkivet, with no licence stated.
- **The church-book page** (Klokkerbok B-5 for Søgne, Greipstad sokn, source 1035) carries a baptism
  transcribed by AMF (Ancestry, MyHeritage and FamilySearch), under a licence labelled only "Ancestry,
  MyHeritage og FamilySearch". Its terms are not published.
- **All five** also carry Arkivverket's own site HTML, scripts and logo, and one carries a page token.
- **No scanned image was ever committed.** The viewer pages link to their scans and embed none.
  Digitalarkivet's own policy (`content/1570`) lets unrestricted scans be reused freely, with
  attribution.

A file does not come under a crate's licence just by sitting inside the crate. ADR 0034 settles which
licence each crate's *code* carries, but neither the MIT/Apache nor the AGPL grant can license
material the project does not own. Nothing asked where a fixture came from, which is how the captures
got in. The other fixtures are already clean:

- the backup archives are generated by `cargo xtask backup-fixture` from invented data (ADR 0041 §5);
- the matching toy fixture is invented;
- the matching corpus holds invented pairs, plus facts transcribed from public records with their
  source URLs.

The real pages are still worth having. They are the only check that the parser keeps up with the live
site, and the site is changing: the new `nye.digitalarkivet.no` viewer is already in the backlog.

## Decision

1. **A committed fixture has one of four origins.** This applies to every file under a `tests/fixtures/`
   tree and under `crates/vitni-core/matching/corpus/`.
   - **`invented`**: data made up for the test.
   - **`generated`**: written by a named xtask, from invented input or from external pages under §4.
   - **`licensed`**: third-party material under a licence that permits redistribution, with that
     licence and its required attribution recorded.
   - **`transcribed-facts`**: facts (names, dates, places, relations) taken from public records, with
     each record's source URL. No copied pages, markup or images.

   A file with none of these origins is not committed.

2. **The origin is declared in a `PROVENANCE.toml`**, in the fixture's directory or an ancestor. The
   nearest one wins. It holds:
   - `origin`, which is always required;
   - `generator` for `generated` (the xtask command that writes the files);
   - `licence` and `attribution` for `licensed`;
   - `sources` for `transcribed-facts` (the records' URLs, or a statement that they are listed in the
     files themselves).

   `cargo xtask fixture-guard` enforces this (#448). It runs in `cargo xtask check` and prek.

3. **Third-party pages we may not redistribute live in an external tier.** A committed manifest lists
   them. For each page it records:
   - the URL;
   - the rights as the source states them, with `redistributable = false`;
   - the facts a test expects to parse from it.

   `cargo xtask fetch-fixtures` downloads the pages into the gitignored `target/`, honouring the site's
   crawl delay. Opt-in `#[ignore]` tests assert the expected facts (#447). This is a manual drift check
   before a release, not a CI job, and pages are not hash-pinned, since live HTML changes. The guard
   fails if a path the manifest lists is tracked.

4. **A fixture may be generated from an external page only if the generator fails closed** (#449). It
   must:
   - prune the page to the elements the parser reads, dropping scripts, styles and site chrome;
   - replace every remaining text and attribute value through a real → invented mapping, and stop on
     any value without a mapping;
   - fail if any real value from the manifest survives into the output.

   The result is recorded as `generated`.

5. **History is not rewritten for the captures committed before this ADR.** They leave the tree (#446)
   and remain in existing commits. If a rights holder asks for their removal, the takedown procedure in
   [`development.md`](../development.md#takedown-removing-a-file-from-history) removes them from every
   commit.

## Rationale

- **An origin is a fact about the file, so it is declared next to it and checked by a machine.** A rule
  that lived only in a document is how the captures got in. A declaration per tree is cheap: one small
  file covers a whole directory.
- **Four origins cover every fixture the repository has or needs.** `invented` and `generated` cover
  our own data. `licensed` leaves room for a genuinely open dataset. `transcribed-facts` covers the
  matching corpus: facts are not protected by copyright, a handful of records is not a substantial
  part of a database, and the source URLs give the attribution the archive asks for.
- **An external tier keeps the value of real pages without redistributing them.** Committing a URL
  and the facts expected from it copies nothing. Each developer fetches the page for themselves, the
  way a browser does.
- **Failing closed is the only safe way to derive a fixture from a real page.** A real page names more
  people than the one a test is about — household members, neighbours in a list, ids in links. A
  substitution that passes unknown values through would leak them silently.
- **Not rewriting history weighs a known cost against a risk nobody has raised.** A rewrite changes
  every SHA since 2026-07-19, drops the GPG signatures on those commits, and breaks every existing
  clone. Removal remains possible at any time, and the procedure has been tested against this
  repository.

## Consequences

### Positive

- Everything committed can be redistributed under the repository's licences, or carries its own
  recorded licence.
- The parser keeps a live-site check, and a site change has a mechanical path back into the bundled
  fixtures (#449).
- A contributor who adds a fixture is told by the guard, at commit time, to say where it came from.

### Negative / costs

- Hand-written or generated pages are simplifications of the real markup. A drift they do not model
  shows up only in the manual external check, so that check has to actually be run before a release.
- The external tests need network access and the site to be up, so they cannot gate CI.
- Every fixture tree carries a `PROVENANCE.toml`.
- The captures remain in the repository's history until a takedown, if one is ever needed.

## Out of scope

- **A rights model for users' own media and sources.** This ADR governs what the repository commits,
  not what Vitni records about a researcher's evidence.
- **Images under `docs/`.** The icons, brand art and README screenshots are the project's own. The
  concept art under `docs/concept-art/` is AI-generated and recorded there as such.
- **A scheduled CI job that fetches from Digitalarkivet.** Polling a public archive from CI is
  impolite and would make CI depend on the archive's uptime.
